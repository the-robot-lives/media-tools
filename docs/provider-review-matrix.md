# Media-tool provider and asset review matrix

Updated 2026-10-27 13:43 +07. Working inventory and review checklist; uncommitted development snapshot.

**Scope:** 222 unique targets: 179 extended library/format types, 15 core families (including audio/voice alias), 15 generation-service guides (9 implemented media adapters and 6 guidance-only services), and 13 LLM connections (12 named-profile presets plus the existing Gemini chat adapter). The five overlapping legacy chat adapters are recorded in their LLM row rather than duplicated. `llm-profile` is a dispatcher, not another provider.

The source catalog contains 410 pages: 179 generation pages + 179 paired documentation pages + 15 core pages + 15 service guides + 22 supplements. Documentation and supplements are evidence links, not additional providers.

## Review legend

- `[x]` verified for that column; `[ ]` pending or not established. Blank evidence means no result recorded. Checkboxes inside table cells are Markdown text (edit `[ ]` to `[x]`).
- Review columns cover semantic/provider-specific acceptance. Structural route checks and regression suites do not complete those reviews.
- **Generated asset** is checked only for actual LLM-generated results. Source-authored examples/fixtures remain unchecked; their provenance appears in notes.
- **Viewer setup** is checked only for an observed render. A registered adapter, installed dependency or text/source preview alone does not certify a native viewer.
- `/tmp` evidence is temporary. Promote accepted fixtures and provider/model metadata into the repository before relying on them as release evidence. Credentials are excluded.
